## 改进建议

- **来源发现率较低**：检查 Discovery 模块的官方来源和权威来源配置
- **资料获取失败较多**：检查 HTTP Client 和 Playwright Client 的错误处理
- **解析失败较多**：检查 Parser 对各种文件格式的支持
- **抽取成功率低**：优化规则抽取逻辑和 LLM Prompt
- **年份识别不准确**：优化年份抽取正则表达式和 LLM 指令
- **单位识别不准确**：检查单位标准化逻辑，防止 MW/GWh 混淆
- **发电量值偏差较大**：检查数值抽取逻辑，防止小数点、千分位等格式问题
