## 1. 启动程序

### 方式一：命令行启动
```bash
cd F:\hydro_platform_v1
python -m hydro_platform.app.gui.main_window
```

### 方式二：直接运行（如果已配置）
双击桌面快捷方式或运行批处理文件

### 启动后
程序会自动打开桌面应用窗口，显示仪表盘页面。

## 2. 界面概览

### 主导航菜单（顶部）
- **仪表盘**: 查看系统概览和统计数据
- **新增数据**: 采集新的发电量数据
- **数据复核**: 审核待复核的数据

- **Top 100**: 查看年度发电量排行榜

- 水电站数量
- 发电记录数量
- 待复核记录数量
- 数据缺口列表（高优先级电站）

## 3. 新增数据

### 3.1 准备工作

1. **选择数据模式**（右上角）
   - **正式数据**: 数据会写入正式数据库并参与统计
   - **测试数据（隔离）**: 在独立数据库中测试，不影响正式数据

2. **填写业务信息**（必填项）
   
   **① 选择目标电站**
   - 点击"搜索电站"输入框
   - 输入电站名称（中文/英文）或 ID
   - 系统会实时显示匹配的电站列表
   - 点击选择目标电站
   
   **② 输入目标年份**
   - 输入数据对应的年份（如 2024）
   - 范围：1900-2100

### 3.2 方式一：网络下载

适用于在线的 PDF、Excel 等文件。

**步骤**：
1. 填写业务信息（电站 + 年份）
2. 输入文件 URL
   - 示例：`https://example.com/report_2024.pdf`
3. 输入来源标题
   - 示例：`三峡集团2024年报`
4. 点击"开始处理"

**系统会自动**：
- 下载文件到本地归档
- 解析文件内容
- 抽取发电量数据
- 进入复核队列或直接入库

### 3.3 方式二：本地文件

适用于已下载到本地的文件。

**步骤**：
1. 填写业务信息（电站 + 年份）
2. 输入本地文件路径
   - Windows 示例：`F:\documents\report.pdf`
   - 支持格式：PDF, Excel (.xlsx, .xls), CSV
3. 输入来源标题
4. 点击"开始处理"

### 3.4 处理结果

**成功入库**
```
✓ 处理成功
已保存 5 条记录
```

**需要复核**
```
⚠️ 需要人工复核
数据已抽取完成，请前往复核中心进行审核
```
- 点击链接跳转到复核中心
- 查看抽取的数据
- 确认或修正后提交

**处理失败**
```
✗ 处理失败
失败阶段：PARSE_FAILED
错误信息：无法解析 PDF 文档
```
- 查看具体失败阶段
- 根据错误信息调整
- 可以重新尝试

## 4. 数据复核

### 4.1 进入复核中心
点击顶部菜单 **"数据复核"**

### 4.2 复核流程

1. **查看待复核列表**
   - 显示所有需要人工确认的数据
   - 包含：电站名称、年份、数值、来源

2. **审核单条记录**
   - 点击记录查看详情
   - 查看原始证据（文件、页码、表格位置）
   - 确认数据准确性

3. **做出决定**
   
   **通过**：
   - 数据准确无误
   - 点击"通过"按钮
   - 数据进入正式库，状态变为 publishable
   
   **驳回**：
   - 数据有误或无法确认
   - 填写驳回原因
   - 点击"驳回"按钮
   - 任务标记为失败
   
   **修正后通过**：
   - 数据大致正确但需微调
   - 修改数值或单位
   - 点击"修正并通过"
   - 更新后的数据入库

### 4.3 批量复核
- 选择多条相同来源的记录
- 批量通过或驳回

## 5. 查看数据

### 5.1 浏览数据页面
点击顶部菜单 **"浏览数据"**

### 5.2 筛选条件
- **电站 ID**: 输入具体电站 ID（如 CN_THREE_GORGES）
- **年份**: 输入年份（如 2024）
- **数值类型**: 实际值/预测值
- **仅显示已发布**: 只看 publishable 状态的数据

### 5.3 数据列表
显示：
- 电站名称
- 年份
- 发电量（GWh）
- 单位
- 数据来源
- 发布状态

### 5.4 查看详情
- 点击记录查看完整信息
- 查看溯源信息（来源文件、证据）
- 查看提取时间和提取器版本

## 6. 测试模式

### 6.1 什么是测试模式
- 使用独立的数据库 `hydro_test.db`
- 使用独立的文件目录 `data/test/raw`
- 不会修改正式数据
- 可以随时清空重新开始

### 6.2 如何使用

**第一步：进入测试环境**
- 点击顶部菜单 **"测试环境"**
- 查看测试数据库状态

**第二步：切换到测试模式**
- 前往"新增数据"页面
- 在右上角数据模式选择器中选择 **"测试数据（隔离）"**
- 卡片边框变为橙色，提示当前在测试模式

**第三步：测试采集流程**
- 按照正常流程添加数据
- 所有数据写入测试库
- 在测试环境页面查看统计

**第四步：清空测试数据**
- 返回"测试环境"页面
- 点击"清空测试数据"按钮
- 确认后删除所有测试数据
- 正式数据不受影响

### 6.3 使用场景
- 学习如何使用系统
- 验证新的数据源
- 测试抽取规则
- 培训新用户

## 7. 常见问题

### Q1: 电站搜索找不到目标电站？
**A**: 
- 检查输入的名称是否正确
- 尝试用英文名或 entity_id 搜索
- 该电站可能未在系统中注册
- 联系管理员添加电站

### Q2: 文件下载失败怎么办？
**A**:
- 检查 URL 是否正确
- 检查网络连接
- 有些网站可能需要登录或有访问限制
- 改用"本地文件"方式：先手动下载，再上传

### Q3: 为什么数据进入复核队列？
**A**: 系统在以下情况会要求人工复核：
- 抽取的数据置信度较低
- 检测到数据异常（如同比变化过大）
- 文件格式复杂，自动抽取不确定
- 首次从某来源抽取数据

### Q4: 如何查看某个电站的历史数据？
**A**:
1. 点击"浏览数据"
2. 在"电站 ID"输入框输入电站 ID
3. 点击搜索
4. 按年份排序查看历史趋势

### Q5: 测试数据和正式数据如何切换？
**A**:
- 在"新增数据"页面右上角
- 看到数据模式选择器
- 下拉选择"正式数据"或"测试数据（隔离）"
- 橙色边框 = 测试模式
- 蓝色边框 = 正式模式

### Q6: 如何查看任务执行详情？
**A**:
- 在"新增数据"页面提交任务后
- 页面会显示 Pipeline 执行过程
- 包括各阶段状态（下载、解析、抽取、入库）
- 失败时显示具体失败阶段和错误信息

### Q7: 数据复核后可以撤销吗？
**A**:
- 已通过的数据可以在"浏览数据"中找到
- 可以手动修改状态或删除
- 建议在测试模式下先验证流程
- 正式数据操作需谨慎

### Q8: 支持哪些文件格式？
**A**: 当前支持：
- PDF 文档
- Excel 文件 (.xlsx, .xls)
- CSV 文件
- 未来将支持更多格式

### Q9: 如何导出数据？
**A**:
1. 进入"设置"页面
2. 点击"导出数据库"按钮
3. 选择保存位置
4. 导出完整的 SQLite 数据库文件

### Q10: 程序出错怎么办？
**A**:
- 查看错误提示信息
- 在测试模式下重现问题
- 查看日志文件（在程序目录下的 logs 文件夹）
- 联系技术支持并提供错误信息

## 8. 最佳实践

### 8.1 数据采集建议
1. **优先使用官方来源**
   - 企业年报
   - 政府公开数据
   - 行业协会报告

2. **填写清晰的来源标题**
   - 包含发布机构
   - 包含文档名称和日期
   - 便于后续溯源

3. **先在测试模式验证**
   - 新数据源先测试
   - 确认抽取准确后再切换到正式模式

### 8.2 数据复核建议
1. **仔细核对原始文件**
   - 点击查看证据
   - 对照原文确认数值

2. **注意单位换算**
   - 系统统一使用 GWh（吉瓦时）
   - 原文可能是 MWh（兆瓦时）或 kWh（千瓦时）

3. **记录驳回原因**
   - 便于后续改进抽取规则
   - 便于追溯决策过程

### 8.3 日常维护
1. **定期查看数据缺口**
   - 仪表盘显示高优先级电站的缺口
   - 有针对性地补充数据

2. **定期备份数据**
   - 使用"导出数据库"功能
   - 保存到安全位置

3. **定期清理测试数据**
   - 避免测试库过大
   - 保持测试环境干净
